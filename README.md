# video-player

갤럭시(안드로이드)용 동영상 플레이어 앱. 코믹뷰어와 같은 구조(즐겨찾기 · FTP · 내 폰 탭)에 N플레이어 느낌의 재생 화면을 붙인다.

## 목표
- FTP 서버의 영상을 내려받지 않고 바로 스트리밍 재생 (집 와이파이 + 외부 LTE/5G)
- 목록에 영상 썸네일 표시 — 첫 장면이 아닌 **30초 지점** 장면 사용

## 설치 방법
코드가 `main`에 올라가면 GitHub가 자동으로 APK를 만듭니다.
저장소의 **Releases → 최신 빌드 → video-player.apk** 를 폰에서 받아 설치하세요.

## 진행 상황
- [x] 1단계: 앱 기본 틀 — 상단 탭(즐겨찾기 · FTP · 내 폰), FTP 서버 저장·수정·삭제, 폴더 탐색, 폴더 즐겨찾기, 설정(테마·목록 크기), 영상 파일만 골라 보기, 길게 눌러 정보·삭제
- [x] 2단계: 재생 엔진(libVLC) — FTP 스트리밍 재생(폰 안 중계로 외부 접속·한글 경로 대응), 탐색 막대, 양옆 두 번 탭 10초 이동, 다 보면 다음 화 버튼
- [x] 3단계: 플레이어 화면 — 밝기·볼륨·탐색 드래그, 외부 자막 자동 연결(SMI·SRT·ASS, CP949→UTF-8 변환), 자막·음성 선택, 자막 싱크, 배속, 화면비, 회전, 잠금, 이어보기·시청 막대
- [x] 4단계: 30초 지점 썸네일(어두우면 뒤 장면 자동 선택, FTP는 필요한 부분만 받기, AVI·WMV·FLV·RMVB는 VLC 엔진으로 추출), 재생시간 표시, 폴더 썸네일 모두 만들기, 시점·LTE 설정
- [x] 5단계: 다음 화 5초 카운트다운 자동재생, 홈 버튼 시 작은 창(PIP), 하드웨어→소프트웨어 디코딩 자동 전환, 이어서 보기 줄, 정렬(이름·최신·용량)
